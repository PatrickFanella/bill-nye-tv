with registry integrity and immutable receipts from Arkhiv source

the preference by collection and retains the current view in memory when
storage writes fail. Browser checks used consumer-owned markup against the
separate vhness-local-fixture collection, generated video and private account
services. Production collection constants were untouched. These checks do
not establish real source audiovisual fidelity or physical device behavior.

changes in memory, but the favorite UI did not disclose that those changes were

Android verification is unavailable without the SDK. Real source playback,
remaining boundary/suspension checks, cross-device sync and provider activation

## Bill Nye layout evidence

The earlier CSS had no header top inset. Reapplying those rules in the owned
browser produced a zero-pixel logo inset at 390px. Current CSS supplies 24px
at both desktop and 390px frame widths, retaining supplied image proportions.
The icon was checked before and after reinstating its earlier inline layout:
its glyph box was displaced by 0.5px on desktop and 0.75px in the narrow frame.
Current grid/span layout centers both axes exactly. The desktop power control
is 42px square; the narrow control is 35px square.

Desktop rendered logo width was 250px; the narrow frame rendered it at 180px.
No horizontal overflow occurred in the 390px frame. These are same-origin
responsive-frame checks, not physical mobile checks. Clicking power entered
standby with aria-pressed false. Enter restored power and displayed a solid
2px focus outline. Asset provenance, CRT styling and optional effects remain.
